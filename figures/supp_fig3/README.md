# Supplementary Fig. 3

The browser on spatial Hi-C-RNA.

* **Made by**: `capture_supp_browser.py` (also makes Supplementary Figs 4 and 5)
* **Reads**: the public atlas stores, opened in the hosted browser
* Whole-page captures, framed as a browser window (`*_framed.png`, `*_framed.tex`).

Run from the repository root, e.g. `python figures/supp_fig3/capture_supp_browser.py`; `python sync_to_paper.py` copies the figure into the paper.
