# Fig. 1

One data model and a linked browser.

* **Made by**: `make_fig1.py`
* **Reads**: illustrations `shared/art/`, ecosystem helpers `shared/ecosystem/`, the atlas counts `benchmarks/atlas/results/atlas.json`
* `gen_image.py` made the illustrations (prompts in `shared/art/PROMPTS.md`).

Run from the repository root, e.g. `python figures/fig1/make_fig1.py`; `python sync_to_paper.py` copies the figure into the paper.
